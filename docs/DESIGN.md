## User Journeys
1. Discover: user finds product in demo or store context.
2. First win: user completes core task in under 60 seconds.
3. Habit: user returns because result is saved, shared, or improved.
4. Fallback: offline or API failure still shows useful cached result.

## UX Principles
* Demo first: every flow must be showable in 30 seconds.
* Simple start: one input, one clear output, progressive detail.
* Trust and clarity: show what Meta AI did and why (labels, confidence).
* Robust live: full live path plus one click cached fallback for stage demos.
* Accessible and fast: readable type, keyboard path, low bandwidth mode.
